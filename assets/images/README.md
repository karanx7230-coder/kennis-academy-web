# Images

All visuals are placeholders — swap them whenever you like:

- **Hero building** → custom inline **2D SVG illustration** in `index.html` (no file needed).
- **Photos** → served live from Unsplash's image API in **WebP** (`images.unsplash.com/...&fm=webp`).
- **Avatars** → randomuser.me API.

Drop real files in this folder (`assets/images/`) and update the `src` when ready.
