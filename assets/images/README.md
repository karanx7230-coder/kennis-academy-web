# 📸 Image Replacement Guide

All images on the site are currently **placeholders** (Unsplash stock photos / randomuser.me API avatars).
Every placeholder has a `🔄 REPLACE` comment directly above it in `index.html`.

Save your real images in this folder (`assets/images/`) using the names below,
then update the `src` in `index.html` as described in each comment.

| Save as              | Used in            | What to put here                                                        |
| -------------------- | ------------------ | ----------------------------------------------------------------------- |
| `building.png` ⭐     | Hero section       | **Academy BUILDING image WITHOUT background (transparent PNG)**          |
| `logo.png`           | Header + footer    | Real Kennis Academy logo (transparent PNG, ~200×200)                     |
| `director.jpg`       | Meet Your Mentor   | Real photo of **Kuljeet Singh** (Director & Faculty)                     |
| `classroom.jpg`      | Primary/Middle cards area / Programs | Real classroom photo                          |
| `exam-prep.jpg`      | Govt Exam Coaching | Students preparing for competitive exams                                 |
| `home-tuition.jpg`   | Home Tuition       | Tutor teaching a student at home                                         |
| `review-1.jpg`       | Reviews            | Real parent/student photo (or keep avatar)                               |
| `review-2.jpg`       | Reviews            | Real parent/student photo (or keep avatar)                               |
| `review-3.jpg`       | Reviews            | Real parent/student photo (or keep avatar)                               |

⭐ **Most important:** the hero expects a **building cut-out with NO background**
(transparent PNG). The hero's navy/gold gradient is designed to sit behind it.

Tip: keep images under ~300 KB each (compress at https://squoosh.app) so the
site loads fast on mobile data.
