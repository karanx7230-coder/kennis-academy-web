# Images

All visuals are placeholders — swap them whenever you like:

- **Photos** → served live from the Unsplash image API in **WebP**
  (`images.unsplash.com/photo-…&fm=webp`). Used in the hero, mentor portrait,
  program cards, cinematic banner, govt-exam panel and home-tuition section.
- **Avatars** → randomuser.me API (reviews).

Each `<img>` has a short `🔄` / placeholder comment nearby. Drop real files in
this folder (`assets/images/`) and update the `src` when ready — e.g. a real
academy photo for the hero, and a real Kuljeet Singh portrait for the mentor section.

Tip: keep photos under ~300 KB (compress at https://squoosh.app) for fast mobile loads.
